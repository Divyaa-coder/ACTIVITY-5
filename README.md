# LeetCode Activity 5 – Java

## Description

This repository contains Java solutions for five LeetCode problems. It focuses on implementing Backtracking algorithms to improve coding efficiency, logical thinking, and problem-solving skills.

## Problems Covered

1. Subsets (78) – Backtracking
2. Permutations (46) – Backtracking
3. Combination Sum (39) – Backtracking and Recursion
4. N-Queens (51) – Backtracking and Constraint Checking
5. Sudoku Solver (37) – Backtracking and Recursion

## Objectives

- Understand and implement backtracking algorithms.
- Develop efficient solutions to combinatorial problems.
- Improve logical thinking and Java programming skills.
- Learn to analyze algorithm performance.
- Apply recursion to solve complex problems.

## Language and Concepts

- Language: Java
- Concepts: Recursion, Backtracking, Arrays, ArrayList, Boolean Arrays, Constraint Checking, and Search Algorithms.
